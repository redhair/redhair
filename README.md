# Hi, I'm Tom Bonanni 👋

Founding engineer at [Parcl](https://parcl.co). I have built onchain real estate markets on Solana since 2021, across every layer of the stack.

## Now

I'm currently working on Parcl v4, a fully onchain order book exchange with cross margin and a dedicated execution layer that settles on Solana. My daily work is exchange infrastructure: matching, margin and liquidation logic, validators, and indexers. Most of it is Rust and TypeScript.

I joined Parcl in 2021 to build the frontend for a real estate trading app. For v1 through v3, I built the apps and parts of the backend. Parcl v3 has done more than $5B in trading volume. Now I work across the whole stack on v4, our own chain, built from scratch.
