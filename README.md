# Hi, I'm Tom Bonanni 👋

Founding engineer at [Parcl](https://parcl.co). I have built onchain real estate markets on Solana since 2021, across every layer of the stack.

## Now

I build Parcl v4, a fully onchain order book exchange with cross margin and a dedicated execution layer that settles on Solana. My daily work is exchange infrastructure: matching, margin and liquidation logic, validators, and indexers. Most of it is Rust and TypeScript.

Almost all of this work is in private repos. Parcl hired me in 2021 to build the frontend. For v1 through v3, I built the apps and parts of the backend. When the author of the v3 smart contract left, I took ownership of it. Parcl v3 has done more than $5B in trading volume. Now I work across the whole stack on v4, our own chain, built from scratch.

## Before

- Built an IoT product from zero to one at a startup. Later worked on big-data backends: billions of rows, SQL, AWS, serverless.
